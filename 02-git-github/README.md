# Git & GitHub for Beginners – Teaching Outline

## 1. Introduction to Version Control
- What is version control? Why do we need it?
    - Every change is stored. You can see what was changed, when, and by whom.
    - Multiple developers can work together without overwriting each other’s changes.
    - You can create a new branch to test features.
- Difference between local files, cloud storage, and Git.
- Benefits of Git: history, collaboration, branching.

## 2. Getting Started with Git
- Installing Git and basic setup (`git config`).
- Understanding the three stages: **Working Directory → Staging Area → Repository**.
- Creating a repository (`git init`) and cloning (`git clone`).

## 3. Basic Git Workflow
- Checking status (`git status`).
- Adding changes (`git add`).
- Committing changes (`git commit`).
- Viewing history (`git log`).
- Undoing mistakes (`git checkout`, `git reset` basics).

## 4. Branching and Merging
- What branches are and why they’re useful.
- Creating and switching branches (`git branch`, `git checkout -b`, `git switch`).
- Merging branches (`git merge`).
- Handling merge conflicts (simple example).

## 5. Introduction to GitHub
- What is GitHub, and how it relates to Git.
- Creating a repository on GitHub.
- Connecting local repo to GitHub (`git remote add origin`).
- Pushing and pulling changes (`git push`, `git pull`).
- GitHub web interface overview.

## 6. Collaboration Workflows
- Forks and pull requests (basic GitHub contribution workflow).
- Issues and discussions.
- Code review process.
- GitHub Actions (just an intro for awareness).

## 7. Practical Best Practices
- Writing good commit messages.
- `.gitignore` basics.
- Keeping main branch stable.
- Small, frequent commits vs. large commits.

## 8. Advanced (Optional, for later lessons)
- Rebasing (`git rebase`) vs merging.
- Stashing (`git stash`).
- Tagging releases (`git tag`).
- GitHub Pages (publishing simple websites).
- GitHub Projects / Actions for automation.
